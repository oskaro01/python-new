# Personal Dictionary

This is your practical Python dictionary project.

Run it with:

```powershell
python my_python_work/personal_dictionary/main.py
```

Each saved word has:

- word
- meaning, optional
- example sentence, optional
- category, optional

The app saves and opens `.json` files.

The app also autosaves after add, edit, remove, and open.

Run tests with:

```powershell
python -B my_python_work/personal_dictionary/test_dictionary_app.py
```

Search now checks:

- word
- meaning
- example
- category

Search results are shown with best matches first.
