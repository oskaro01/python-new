# Shopping App

This is the split-file version of your shopping list project.

Run it with:

```powershell
python my_python_work/shopping_app/main.py
```

Files:

- `main.py` starts the app.
- `shopping_list_app.py` contains the `ShoppingListApp` class.
- `file_dialogs.py` contains the Windows open/save popups.
