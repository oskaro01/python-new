# OOP Practice

This folder is for learning classes properly before the full review session.

OOP means Object-Oriented Programming. It is a way to group data and behavior together.

Simple memory hook:

```text
Class = blueprint
Object/instance = real thing made from blueprint
Attribute = data inside the object
Method = action the object can do
Inheritance = child class reuses parent class
Polymorphism = same method name, different behavior
Abstraction = hide messy details behind simple methods
Encapsulation = protect/control how data changes
Composition = one object owns/uses another object
```
