# 🐍 Python Learning Guide

A comprehensive collection of Python examples organized by topic, based on the [QuickRef Python Cheat Sheet](https://quickref.me/python).

## 📁 Folder Structure

| # | Folder | What You'll Learn |
|---|--------|-------------------|
| [01](01_getting_started/) | **Getting Started** | Hello World, variables, data types |
| [02](02_strings/) | **Strings** | Creating, slicing, f-strings, formatting |
| [03](03_numbers_arithmetic/) | **Numbers & Arithmetic** | Math operators, type casting |
| [04](04_lists/) | **Lists** | List basics, slicing, comprehensions |
| [05](05_tuples_sets_dicts/) | **Tuples, Sets, Dicts** | Immutable sequences, unique sets, key-value maps |
| [06](06_flow_control/) | **Flow Control** | if/elif/else, for/while loops, break/continue |
| [07](07_functions/) | **Functions** | Definition, *args/**kwargs, lambda functions |
| [08](08_classes/) | **Classes & Inheritance** | OOP basics, inheritance, polymorphism |
| [09](09_modules/) | **Modules** | Importing, built-in modules |
| [10](10_file_handling/) | **File Handling** | Read/write files, JSON |
| [11](11_error_handling/) | **Error Handling** | try/except, custom exceptions |
| [12](12_advanced/) | **Advanced Topics** | Heaps, deque, generators |

## 🚀 How to Use

**Run any file with Python:**
```bash
python 01_getting_started/hello_world.py
```

**Recommended order:**
1. Start with `01_getting_started/` → `04_lists/`
2. Then `05_tuples_sets_dicts/` → `06_flow_control/` → `07_functions/`
3. Move to `08_classes/` → `10_file_handling/` → `11_error_handling/`
4. Finish with `12_advanced/`

Each file contains:
- ✅ Working code examples
- 📝 Explanation comments
- 🧪 "Try it yourself" exercises at the end
